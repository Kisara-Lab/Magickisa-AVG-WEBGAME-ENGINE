# 创作生产升级实施记录

目标版本：2.0.0-dev.5。工作分支：`feat/creator-production-dev5`。

本文件记录实施与验收结果。交付 PR 为 [#72](https://github.com/Kisara-Lab/Magickisa-AVG-WEBGAME-ENGINE/pull/72)，最终合并状态与提交以该 PR 为准。

## 已确认契约

- 工程与玩家存档升级到版本 3，工程包版本 2，Studio 创作资料版本 2。不维护旧开发版转换器，不改写旧文件和存档。
- 只有现代运行时。空白工程是唯一创建起点，不分发教学剧情或素材。
- 三类用途共用模型：视觉小说、GALGAME、单人文字调查。调查仍以选择、资料、变量及条件效果表达。
- ADV/NVL、可视主题、图片/音频/视频、多轨关键帧演出；Live2D 保留外部适配器。
- 演出不能执行脚本、变量效果和剧情跳转。统一时钟、有限指令、确定终态，恢复或跳过不重复剧情效果。
- Studio、CLI、Agent 共用编辑操作、校验和持久化规则；剧情测试使用真实运行时。
- 最终交付包括审计、文档、截图、跨平台 CI、集成 PR、合并提交源码 ZIP 与 SHA256。

当前工作流操作说明见 [创作工作流](CREATOR-WORKFLOW.md)。以下总项仍需完整集成验收，不能据局部测试标记整体完成。

### 已实施并完成局部验证

- 共享事务操作、局部场景更新、补丁撤销、范围替换、多行正文导入与多选台词移动／复制／删除。
- 格式 3 稳定台词定位、ADV/NVL 和主题配置、台词配音、多轨采样／等待／恢复／跳过与终态保留。
- 时间轴鼠标与键盘调整、吸附、可视关键帧；已通过专门浏览器的拖动、撤销及 390px 检查。
- 512 MiB 流式素材导入与取消清理、视频选择器；9 MiB 生成素材往返哈希检查通过。
- 元数据备份列表／差异／协调恢复及 CLI 入口；过期 revision、备份变化和创作资料冲突拒绝测试通过。
- 声明式路线测试与 CLI/Studio 报告；非法初始状态单项失败，不中断其他测试。
- 预览录制生成路线测试、实际条件求值覆盖、运行时事件订阅及跨周目画廊已实现，包含内存预览隔离和存储失败保护。
- 素材原位替换、引用保护删除、历史恢复、媒体元数据与 CLI 检查方案已实现。恢复同时核对工程 revision、当前素材和备份 SHA256。
- 演出轨道支持会话内锁定、独奏预览、排序和音量包络；作者可复制、导出和检查导入演出预设，副本生成独立 ID。
- Windows 本地已通过完整 Studio、玩家浏览器、CLI、Agent 同步与许可清单检查；66 项单元测试、类型检查和 Studio 构建通过。Node 22 的 CLI 完整闭环也已本地通过。
- 变量重命名已覆盖工程、注释、测试初始状态及断言，CLI 与 Studio 均使用检查方案，协调提交只生成一次备份。
- 子路径发行已通过独立静态服务器加载检查；NVL 长段滚动／分页、画廊隐藏未解锁内容、媒体失败重试／等待／跳过／终态已通过浏览器验证。
- 生成的 1,000 场景／20,000 台词／5,000 连接工程已通过浏览器加载、邻域筛选和编辑检查，本机该组合步骤约 2.56 秒。这是单机观测值，不是跨平台性能保证。
