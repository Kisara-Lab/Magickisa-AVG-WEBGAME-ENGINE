## 资源放在哪里

每个工程有自己的 `public/`，即使路径同名也按工作区分别读取：

```text
workspace-projects/<workspaceId>/public/
  images/hall.webp
  portraits/detective.png
  audio/theme.mp3
  lyrics/opening.lrc
```

对应字段路径为 `/images/hall.webp`、`/portraits/detective.png`、`/audio/theme.mp3`、`/lyrics/opening.lrc`，不包含 `public` 目录名。

素材库支持搜索、类型筛选、多文件选择与拖入，逐文件显示结果；图片可预览、音频可试听，背景、立绘和演出入口可直接打开素材选择器回填。上传使用唯一文件名策略，实际资源路径以结果为准。

单文件上传限制为 **8 MB**，支持 png、jpg、jpeg、webp、svg、mp3、ogg、wav、lrc。更大音频可手工放入当前工程的 `public/` 后填写路径；工程包会收录满足包规则的全部素材，包括未使用素材。

不要使用本机绝对路径、临时 blob 链接或另一工程的预览地址作为可迁移资源。保留外链时，预览与发行依赖外站可访问性和浏览器限制，导出不会自动下载它们。

## 背景与人物

1. 上传背景并登记背景 ID／src，在场景中选择背景。
2. 在人物页新增人物，设置名称、默认立绘与表情映射。
3. 在台词中选择人物与表情；需要多人同屏时展开立绘图层。
4. 精调位置、x／y、缩放、透明度、层级与入场参数；可选数字清空表示恢复默认值。
5. 在手机预览中检查人物是否遮挡台词或分支。

资源 ID 与路径由既有解析规则处理；使用选择器可减少手写错误。图层需要人物 ID，不要把说话人显示名称当作人物引用。Live2D 仅提供适配器和生命周期接口，Cubism SDK、模型及相关授权需自行准备。

## 音轨、章节音乐与鉴赏

`audio[]` 登记可由 `setAudio` 引用的音轨；`trackId` 填已登记的 ID，不能直接把文件路径填进该效果。

章节音乐由 `media.chapterMusic` 与关键词规则配置；显式指定音轨优先于章节规则。避免空关键词和过宽规则，修改后预览实际场景。曲目音量与全局音量相乘，音乐鉴赏暂停章节 BGM，同时只播放一首鉴赏曲目。

鉴赏列表可配置标题、作者、src、mood、unlockNode。解锁使用稳定场景 ID；不要依赖场景数组下标。浏览器可能要求先点击页面才允许播放声音。

## 启动标识、献词与演出触发

引擎启动标识属于游戏启动流程；献词、OP、ED 在演出页编辑。编辑器的演出预览可用于检查片段，但配置好媒体不等于所有剧情场景都会自动触发它。

在剧本页“场景演出”字段中选择：

- 普通剧情：不指定特殊演出。
- 开场献词 → OP：对应 `presentation: "dedication"`。
- 结局 → ED：对应 `presentation: "ending"`。

现代档通过场景演出字段触发，单独增加标签不会触发献词。两种模式都应从新游戏实际走到相关节点检查，不仅使用片段预览。`sequenceId` 是保留元数据，不是可注册独立演出序列的入口；`ending` 是结局标识，也不代替场景演出配置。

## 献词

在献词页按页面列表新增、选择和编辑，每页保存若干行文字，可设置标题与提示。配置位于 `media.dedication`：

```json
{
  "title": "献给每一位读者",
  "pages": [["故事从一封信开始。", "请在黄昏前回来。"], ["愿你找到自己的答案。"]],
  "hint": "点击继续"
}
```

把对象用于对应 dedication 字段，不要替换整个 media。预览分页文字长度和换行，再检查献词结束后的 OP 衔接。

## OP

在演出页选择 OP，配置：

| 字段 | 内容 |
| --- | --- |
| `audio`、`duration` | 音乐路径与总时长，单位秒 |
| `images` | 镜头图片路径数组，顺序即播放顺序 |
| `pages` | 内嵌字幕，条目为 `{ "at": 2.5, "text": "字幕" }` |
| `lyrics` | 可选外置歌词路径 |
| `credits` | 作者、网站、制作等署名参数 |

通过缩略图排序或前后移动镜头；时间轴支持缩放、点击定位与字幕时间点拖动，数字输入用于精调。拖动结束形成一次撤销操作。

镜头节奏由既有运行时决定，不存在逐镜头独立时长字段。兼容档保留每镜头 14 秒的历史节奏；署名依赖镜头位置，请处理检查中关于镜头数量的提示。无音频或播放受阻时使用计时后备，默认 OP 时长 89 秒；按实际作品配置并完整播放检查尾部。

## ED

配置 `media.ending` 的 audio、duration、image、title、lyrics，以及双语 `lines`：

```json
[
  { "at": 0, "en": "At dusk", "zh": "黄昏时分" },
  { "at": 5.5, "en": "We meet again", "zh": "我们再次相遇" }
]
```

上面是 lines 字段的值，时间单位为秒。鸣谢 `credits` 是字符串数组，模式 `creditsMode` 支持：

- `crawl`：滚动鸣谢，`creditsDuration` 设置滚动时长，编辑器默认 42 秒。
- `slides`：每七秒轮播。

无音频时默认 ED 计时后备为 198 秒。音频、字幕末句和鸣谢结束应一起检查，不要只确认开头能播放。

## 字幕与演出排错

| 现象 | 处理 |
| --- | --- |
| 缺失外置歌词提示 | 兼容工程有内嵌定时字幕时可作为警告继续；展开说明确认采用内容 |
| 时间点无法精调 | 检查单位为秒、值有效；未应用数字不会进入工程 |
| 镜头顺序错误 | 检查 images 数组顺序，不通过文件名排序猜测 |
| 配置献词后剧情不播放 | 检查场景演出字段与实际到达节点 |
| 无声但画面推进 | 检查音频路径、静音、音量与浏览器自动播放限制 |
| 发行后资源 404 | 检查项目 public 路径与文件名大小写，确认未使用本机路径 |

保存工程后完整测试“新游戏 → 标识 → 相关开场／剧情 → 结局演出”，再构建发行包。
