## 使用边界

每槽只保留最近一份恢复副本。恢复已有槽位会先备份当前值，可往返最近两次状态；请定期导出重要进度。收藏重建先在原键的 `:recovery` 留存原始字节，再写本次获得的收藏，无法推断损坏记录中的旧解锁信息。

资料解锁条件决定获得时机；获得后不因条件回落消失。插值检查为警告，允许外部赋值，仍需真实预览。界面开关控制可选入口，不删除数据；存读档、设置和主菜单始终可用。

工程包保留项目文档原文；换机后的 Agent 必须先读取实际新工作区 ID，不能沿用文档里记录的旧 ID。

## 同步裁决

同一份原稿被选择“保留当前”后，重复 plan 会列出 deferred。需要重新采用时，在 resolutions 对该稳定路径选择 `take: "incoming"`。被拒记录子树的原稿改变后重新比较，不按标题或正文相似度接管。

## 损坏锁恢复

doctor 的 `state: "unknown"` 表示归属文件缺失或损坏，不能证明持有进程已经退出，因此禁止自动强制解锁。关闭本引擎全部 Studio、CLI、构建与启动器；无法确认残留进程时重启电脑，先不要启动引擎。将 doctor 指出的单个锁目录复制到引擎目录外留存，再离线移除该已核对的锁目录，重新执行 doctor。不要删除工程、备份或其他未核实路径。
