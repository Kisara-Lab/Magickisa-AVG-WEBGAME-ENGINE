# MAGICKISA v2.0.0 — Studio、CLI 与 Agent 创作正式版

MAGICKISA 是开源网页 AVG／视觉小说引擎，附带熔金色 Studio 和面向开发者、AI Agent 的 CLI。本版是首个 V2 正式版本，仅支持现代运行时，适合视觉小说、GALGAME 和单人侦探调查／非线性文字叙事。

## 先体验成果

**[▶ 游玩《伊尔玛林的黄昏》](https://ilmarin.kisara.info/)**

成果站点独立维护，不保证使用此版本。本次发布不更新站点。游戏剧情、美术、音乐等单独授权，不包含在引擎附件中；引擎、Studio 与自有品牌 SVG 使用 MIT。

## 本版能做什么

- **可视化创作：** 连续台词、人物表情与图层、章节导航、全局命令搜索、高级 JSON、批量编辑、撤销重做。
- **复杂流程与调查：** 图上连线、侧栏精编、自环与地点回访、自动布局、章节／邻域视图、资料线索、递归条件、变量、测试状态和真实门槛解释；缩略图可关闭以避免遮挡端口。
- **演出：** ADV／NVL、作品主题、逐句配音、多轨舞台与视觉关键帧、音量包络、引擎标识、献词、OP／ED 与字幕编排。
- **玩家体验：** 可选逐字显示、字号等阅读设置、自动／已读快进、历史搜索、逐条资料已读、12 个手动存档槽、恢复副本、跨周目收藏和多标签页写权限保护。作者可选择显示锁定分支，默认仍隐藏。
- **CLI／Agent：** 独立运行命令、JSON 原子事务、上下文与 schema、TXT／Markdown／JSON 来源登记、多文件结构稿、三方增量同步、人工修改冲突保护、声明式路线测试与构建。
- **工程维护：** 整体工程＋全部素材包、独立导入、512 MiB 流式素材上传、引用检查、原位替换与恢复、协调备份、revision 和跨进程写锁、子路径发行。

近期修复包括故障配音阻塞阅读、重复完成效果、资料解锁持久性、音乐收藏、排队通知、损坏收藏恢复、窄屏导航、演出数值输入、变量误写警告与实际条件／跳过台词诊断。详见 [CHANGELOG](../../CHANGELOG.md) 和 [Issue 核查记录](../ISSUE-HARDENING.md)。

## 下载与启动

| 附件 | 用途 |
| --- | --- |
| `MAGICKISA-v2.0.0-Studio-start.zip` | 跨平台联网启动包，普通作者优先下载 |
| `MAGICKISA-v2.0.0-source.zip` | 完整发布提交源码，供引擎开发与归档 |
| `SHA256SUMS.txt` | 校验上述两项附件 |

**需预装 Node.js 22+（含 npm）和现代浏览器，首次运行必须联网安装依赖。** 包内不附 Node.js、依赖、浏览器、用户工程或游戏内容。解压到可写目录，不要直接从压缩包运行。

- Windows：双击 `Start-Studio.cmd`。
- macOS：双击 `Start-Studio.command`，或执行 `sh Start-Studio.command`。
- Linux：执行 `sh Start-Studio.sh`。

启动器检查环境并安装依赖，打开工程管理页。服务仅监听 `127.0.0.1`，实际地址以终端为准；保持终端运行，按 Ctrl+C 停止。同一引擎目录只运行一个 Studio。安装失败请修复网络或 Node 环境后重试；不会留下安装成功标记。

创建空白工程或导入 `.magickisa.zip` 后，即可编辑、手动更新预览、保存与构建。新工程不附教学剧情或媒体。构建输出为项目 `dist/`，部署后玩家无需 Node.js。静态 `dist-studio/` 不能替代完整本地服务。

源码安装也可使用 `npm ci`、`npm run dev`。CLI 入口为 `node scripts/magickisa.mjs help`，普通 CLI 命令不要求启动 Studio。

## 校验下载

Windows PowerShell：

```powershell
Get-FileHash -Algorithm SHA256 .\MAGICKISA-v2.0.0-Studio-start.zip
```

Linux：`sha256sum -c SHA256SUMS.txt`。macOS：`shasum -a 256 -c SHA256SUMS.txt`。两项 ZIP 与校验文件应放在同一目录，核对输出与文件名。

## 升级与兼容

- 正式版沿用 dev.5 数据格式：**工程／玩家存档 3，工程包 2，Studio 创作资料 2**。仅版本号变化不要求 dev.5 数据转换，工程内部内容版本及稳定 ID 仍由作者管理。
- dev.0–dev.4、旧格式 1 包和 Legacy 文件不自动转换。升级前保留原引擎、工程目录、整体工程包和玩家存档；不要修改 schemaVersion 冒充转换。
- 兼容运行时已经移除；旧兼容作品继续使用冻结的 [v1.0legacy](https://github.com/Kisara-Lab/Magickisa-AVG-WEBGAME-ENGINE/releases/tag/v1.0legacy)，不提供后续维护或转换工具。
- Studio 未应用 JSON 必须先处理；浏览器草稿不等于磁盘工程已保存。外部修改和旧 revision 会拒绝覆盖。

## 已知边界

- 不提供多人联网、主持人、举证界面、云存档或专用任务模型。
- Agent 自行理解自然语言；引擎不调用模型、不执行用户 JS／TS，没有 MCP 或专用剧本语法。同步和静态连通不能替代真实剧情预览。
- 浏览器验收使用 Chromium；媒体编码、自动播放和全屏能力由浏览器决定。Live2D 需自行提供适配器、模型、SDK 及许可。
- 安全玩家存档需要 Web Locks 与 HTTPS／本机环境；缺少能力时可使用明确的临时游玩并导出。预览始终用内存，不接触真实玩家存档。
- 外链素材仍需联网；工程包不自动下载外链，不包含浏览器草稿、玩家存档或引擎。未知归属的残留锁不能强制抢占，按文档离线恢复。
- 本次只发布源码与联网启动包，不发布 npm 包或托管服务，不修改成果站点。
